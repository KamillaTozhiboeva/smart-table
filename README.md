# Smart Table

Интерактивное веб-приложение для структурированного отображения и управления массивами данных. Проект демонстрирует навыки работы с клиентским состоянием, реализацию алгоритмов сортировки и динамический рендеринг интерфейса.

## Функциональность
* **Динамический рендеринг:** Мгновенная отрисовка данных на основе пользовательского взаимодействия.
* **Сортировка данных:** Упорядочивание строк по выбранным колонкам (по возрастанию и убыванию).
* **Фильтрация:** Инструменты для быстрого поиска и изоляции нужной информации.
* **Адаптивная верстка:** Корректное отображение элементов таблицы на различных устройствах.

1. Установите зависимости:
   ```bash
   npm install
  ```

2. Запустите проект локально:
    ```bash
    npm run start
    ```
